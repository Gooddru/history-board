# 📜 Исторический веб-сайт: Интерактивные доски по Истории Россиии

Образовательный многостраничный веб-проект, созданный для интерактивного изучения ключевых периодов отечественной истории. Проект включает в себя визуальные блок-схемы, таймлайны, подробные аналитические таблицы и навигационный портал.

---

## 📂 Структура проекта

```text
history-boards/
├── index.html           # Главная страница-портал с навигацией
├── romanovi.html        # Интерактивная доска: Династия Романовых (XVIII век)
├── dekabristi.html      # Доска и сводная таблица: Общественные движения XIX века
├── nevsky.html          # Инфографика и таймлайн: Князь Александр Невский
└── images/              # Папка с локальными иллюстрациями и фоновыми изображениями
    
```

---

## Основные разделы и возможности

1. **Главный портал (`index.html`)**:
   * Стильный стартовый экран с фоновыми иллюстрациями.
   * Удобные карточки для быстрого перехода к любой исторической доске.

2. **Доска «Романовы» (`romanovs.html`)**:
   * Музейный стиль оформления в теплых тонах пергамента.
   * Генеалогические связи правителей XVIII века и векторные стрелки переходов.
   * Разбор внешней политики монархов и текста Устава о наследовании престола 1722 года.

3. **Доска «Декабристы и общественные движения XIX века» (`decembrists.html`)**:
   * Интерактивная блок-схема организаций (от декабристов до народников).
   * Возможность масштабирования, перетаскивания карточек и панорамирования холста.
   * Модальные окна с детальным разбором программ по пунктам (А–Г).
   * Встроенная интерактивная сводная таблица с функцией поиска по всем обществам.

4. **Доска «Александр Невский» (`nevsky.html`)**:
   * Структурированная инфографика XIII века.
   * Сравнение западной и восточной политики князя.
   * Интерактивный таймлайн ключевых дат и сражений (Невская битва, Ледовое побоище).

---

## 🛠️ Технологии

* **HTML5 / CSS3** (Flexbox, Grid, CSS Variables, Backdrop Filter).
* **JavaScript (Vanilla)** (Интерактивное управление состоянием, фильтрация таблиц, динамическое рисование связей).
* **SVG** для векторных стрелок и схем.
